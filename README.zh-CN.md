## 概述

Nemo 让您把想到的事情写在便笺上,贴在桌面上。每张便笺由标题和正文组成,停止输入后会自动保存。可以为每张便笺指定颜色,也可以把它置顶在其他窗口之上;下次启动 Nemo 时,便笺的位置、大小和置顶状态都会原样恢复。

便笺**首先保存在本机**,因此无需登录、即使没有网络也能照常使用。使用 Kilho.net 账户登录后,便笺会与服务器同步,您可以在其他电脑上的 Nemo 和 [Web Memo](https://webmemo.kilho.net) 中查看和编辑同一批便笺。

## 主要功能

- **桌面便笺** — 便笺窗口不占用任务栏和 Alt+Tab,关闭列表窗口后仍留在桌面上。
- **自动保存** — 停止输入 3 秒后或点击其他地方时自动保存,没有保存按钮。
- **记住位置** — 记住便笺的位置、大小、置顶以及哪些便笺处于打开状态,下次启动时原样恢复。
- **6 种颜色** — 默认 · 黄色 · 绿色 · 蓝色 · 紫色 · 粉色。列表中每一行的背景也是便笺的颜色,一眼就能区分。
- **置顶** — 置顶的便笺不会被其他窗口遮挡。
- **搜索便笺** — 用列表窗口的放大镜搜索标题和正文。
- **新建便笺快捷键** — 无论正在使用哪个程序,按 **Ctrl+Shift+N** 即可打开新便笺。快捷键可以更改。
- **无需服务器** — 登录是可选的。退出登录后,本机上的便笺仍会保留。
- **在多台电脑和网页间同步** — 登录后,在保存 2 秒后、每 10 分钟一次,或点击 **立即同步** 时与服务器同步。如果同一张便笺在两处被修改,两边都不会丢弃,其中一份保留为 **冲突副本**。
- **通过浏览器安全登录** — 无需在 Nemo 中输入密码,在您常用的浏览器中用 Kilho.net 账户登录(OAuth 2.0 + PKCE)。
- **表情符号** — 标题和正文中都可以加入表情符号。
- **22 种语言** — 跟随 Windows 显示语言,也可以在设置中自行选择。

## 使用方法

### 开始使用

1. 启动 Nemo。列表窗口打开,通知区域(托盘)中出现 Nemo 图标。
2. 右键单击列表的空白处或托盘图标,选择 **新建便笺**。(在任何地方按 **Ctrl+Shift+N** 也可以。)
3. 新便笺会先打开标题栏。输入标题后按 **Enter** 进入正文。
4. 输入正文。停止输入 3 秒后便笺会被保存,并出现在列表中。
5. 把便笺放在桌面上任意位置即可。拖动标题栏移动,拖动边缘调整大小。
6. 看完后点击便笺的 **✕**,便笺会保存并关闭。要再次打开,在列表中双击该便笺。

### 常见用法

**工作中突然想到什么时**
即使正在使用其他程序,按 **Ctrl+Shift+N** 就会在最前面弹出一张新便笺。输入标题、按 Enter、输入正文后放着不管,它会自动保存。

**想让便笺一直可见时**
点击便笺上的图钉开启 **置顶**,打开其他窗口也不会挡住它。再点一次即可关闭。置顶状态在下次启动时也会恢复。

**便笺被其他窗口挡住时**
左键单击托盘中的 Nemo 图标,所有打开的便笺都会显示到最前面,列表窗口保持不动。需要列表窗口时,右键单击托盘图标并选择 **列表**。

**想按类别区分便笺时**
可以给不同用途定好颜色,比如待办用黄色、工作用蓝色。右键单击便笺标题栏或列表中的便笺 → **颜色 ▸** 选择颜色,便笺和列表中那一行的颜色会立即改变。

**便笺太多、不好找时**
点击列表窗口标题栏的放大镜,输入要找的内容。只会留下标题或正文中包含该内容的便笺。按 **ESC** 关闭搜索,回到完整列表。

**只想改标题时**
单击便笺标题,稍等片刻再单击一次(就像在文件资源管理器中重命名一样),或者双击标题,或者右键单击标题栏 → **编辑**。**Enter** 确认,**Esc** 恢复原来的标题。点击其他地方也会按输入的内容确认。

**想收起列表、只留下便笺时**
点击列表窗口的 **✕**,它会进入托盘,便笺仍留在桌面上。要完全关闭 Nemo,请在托盘菜单中选择 **退出**。

**下次仍在原来的位置**
即使在便笺打开的状态下关闭 Windows 或退出 Nemo,下次启动时打开过的便笺也会以相同的位置和大小重新出现。如果因为显示器配置改变而跑到屏幕外,会被移回屏幕内显示。

**想每次开机都看到便笺时**
在设置 **常规** 中开启 **开机时运行**(安装版默认已开启)。Windows 启动后,Nemo 会不显示列表窗口、安静地在托盘中启动,只有之前打开的便笺出现在桌面上。

**想在公司和家里的电脑上使用同一批便笺时**
在两台电脑上都到设置 **服务器** 点击 **登录**。浏览器打开后用 Kilho.net 账户登录,出现"已登录"页面后关闭该窗口,回到 Nemo 即可。之后便笺会在保存 2 秒后以及每 10 分钟自动同步。想马上同步时,点击 **立即同步**。

**不在电脑旁时**
用在 Nemo 中登录的账户进入 [Web Memo](https://webmemo.kilho.net),即可查看和编辑同一批便笺。在网页上的修改会在下次同步时进入 Nemo 的便笺。

**同一张便笺在两台电脑上分别被修改时**
不会覆盖任何一方。一份保留为原来的便笺,另一份成为标题末尾带有 **(冲突副本)** 的新便笺。比较内容、合并成一份后,删除不需要的那一份即可。

**登录之前就已经有便笺时**
登录后,本机上的便笺会上传到该账户,服务器上的便笺会下载到本机,合并为一个列表。如果这台电脑以前用其他账户登录过,Nemo 会先询问"您登录了另一个账户。要将此电脑上的便笺合并到此账户吗?",选择 **否** 则不会登录。

**想停止同步、只在本机使用时**
在设置 **服务器** 中点击 **退出登录**。本机上的便笺仍会保留,状态栏会变为 **仅保存在此电脑**。服务器上的便笺和其他电脑不受影响。

**没有网络时**
便笺总是先保存在本机,照常使用即可。网络恢复后,会在下次同步时上传到服务器。

**想更改新建便笺快捷键时**
在设置 **常规** 中点击 **快捷键（新建便笺）** 框,它会变为"请按键"。按下想要的组合键(例如 Ctrl+Alt+M)即可立即生效。如果该组合键已被其他程序占用,Nemo 会提示您,请换一个组合。

**想放在 U 盘里随身使用时**
把免安装版解压到 U 盘并在那里运行。便笺保存在同一文件夹中,插到哪台电脑上都会打开同一批便笺。

**卸载后重新安装 Nemo 时**
卸载安装版不会删除便笺。重新安装后,原来的便笺依然都在。

**关闭 Windows 时**
Nemo 不会阻止关机。它会保存正在编辑的便笺,然后随 Windows 一起关闭。

**再次启动 Nemo 却看不到窗口时**
Nemo 同一时间只运行一个。如果在已经运行时再次启动,隐藏在托盘中的列表窗口会显示到最前面。

## 设置

从列表窗口的齿轮或右键菜单的 **设置** 打开。更改立即生效,没有确定按钮。

| 分类 | 项目 | 默认值 |
|---|---|---|
| 常规 | 开机时运行 | 安装版开启,免安装版关闭 |
| 常规 | 快捷键（新建便笺） | Ctrl+Shift+N |
| 常规 | 语言 | 系统(Windows 显示语言) |
| 服务器 | 账户 — 登录 / 退出登录 | 未登录 |
| 服务器 | 同步 — 上次同步时间、立即同步 | 仅在登录时显示 |
| 关于 | 版本 · 作者 · 主页 · 许可证 | — |

语言为 **系统** 时跟随 Windows 显示语言;从列表中选择后会当场切换。阿拉伯语从右向左显示。
